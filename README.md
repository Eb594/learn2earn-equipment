# Learn2Earn Equipment Lending

A simple Python command-line program for managing equipment borrowed by Learn2Earn fellows.

## Features

* Add and list equipment
* Borrow equipment
* Return equipment
* Search equipment by name
* Filter equipment by category
* Generate inventory reports
* Save data using JSON

## Requirements

* Python 3

No external packages are required.

## How to Run

```bash
python3 main.py
```

## Purpose

The project helps Learn2Earn track equipment inventory, borrowing, returns, and available stock.
